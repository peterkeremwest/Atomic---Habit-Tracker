- **DynamoDB (same `AtomicTable`, no new table):** `pk = LIST#<id>` with `sk = META` (title, link, members, version), `ITEM#<id>` (one per item), `INVITE#<code>` (single use, 48 h). Pointer rows `pk = USER#<sub>`, `sk = SHARED#<id>` per member. The pull returns `memberOf`; a list missing from it is dropped locally unless it has pending outbox entries.
- **IndexedDB:** version 1 → 2, adds `slists` and `sitems`. Existing data is untouched (upgrade tested).
- **Stack:** new Lambda `SharedFunction` (`nodejs24.x`, arm64) with six explicit-method routes on the existing authorizer, log group and error alarm. Deploy: `cd backend && sam build && sam deploy` from the owner's terminal.
- Item and list objects may carry `link`. Lists have `doneBy`/`doneAt` per item.

**Cumulative Capabilities**
Atomic is a working, installable web app that lives on the phone and works without internet. It is hosted by Cloudflare at app.atomicapp.workers.dev and rebuilt automatically every time new code reaches GitHub. Everything you enter is kept in a filing drawer on the device itself (IndexedDB), and every change also drops into an outgoing-mail tray. Since v0.2 that tray has somewhere to go: an AWS back office. You sign in with the same account as Forge (one badge office, Cognito, issues badges for both buildings), and your changes are carried to a filing cabinet in the cloud (DynamoDB) through a front desk with a bouncer (API Gateway with a Cognito check) and a data clerk (Lambda). Pulls only ask for pages filed since your last visit, and when two copies of the same item disagree, the newer one wins. A second phone signed in to the same account ends up with the same items. The back office has a $5 monthly budget alert, an error alarm, an hourly-and-nightly photocopy of the cabinet, and a queue rope at the front desk.

The main screen shows one day at a time. You move between days with arrows or a month calendar, and a BACK TO TODAY button appears whenever you wander off. A typing box understands plain sentences. `#fitness workout monday wednesday friday` makes a weekly habit, `buy groceries on Friday` makes one task for the coming Friday while `on Fridays` repeats every week, `#timeblock work 5pm - 11pm` blocks out time, `#list groceries: eggs, soap` makes a checklist, `car repair: tires $10, brakes $50` makes an expense list with a total and a share bar, `move out: pack, clean` makes a task with steps, `study 25 min timer` makes a habit with a countdown, `#ongoing learn spanish` makes a goal that stays until it's done, and `#note books to read: dune` files a note. Unknown tags create new categories, and a category name can never exist twice: copies are merged automatically.

The day is grouped into foldable sections: FOCUS, SCHEDULE, DAILY, WEEKLY, MONTHLY, ONE-TIME, ONGOING, LISTS, SHARED, EXPENSES and NOTES. Checked items stay visible and crossed out. Ongoing goals appear every day until you finish them, and finished ones can be kept in view. Items can be dragged into your own order, unfinished tasks can be pushed to tomorrow in one tap or to any day from a calendar, and almost every action can be undone for five seconds. Dates are picked from Atomic's own month grid, which works the same on every phone. The NOTES tab keeps lists and writing that don't belong to a day (books, recipes, quotes, reminders), and any note can be pinned to show on Today every day. The Habits screen shows streaks and the last 12 weeks, the Calendar marks planned, partly done and fully done days, the weekly review sums up each week, and search finds anything. The look is an old terminal in green, amber, red or pink.

Since v0.2.5, a list can be shared with exactly one other person (`#shared errands: milk, soap`). Both people have full control: either can add, check, remove, rename or delete items, and each checked item shows who checked it. One person creates an invite code or link, the other enters it after signing in, and the code works once and expires after 48 hours. Shared lists live in their own shelf of the cloud filing cabinet, so two people checking different items at the same moment never overwrite each other, and they appear in a SHARED section on Today beside your private items, marked with a two-person icon. Web addresses typed into an item, step or note become tappable, and any list or note can carry a link button (for example to a store's shopping list); on a shared list both people see it.

What it can't do yet: there are no reminders or notifications, and nothing is shared with Forge's workouts yet, and shared lists hold two people at most. Those come with the Forge ↔ Atomic sync and the reminders phases.
