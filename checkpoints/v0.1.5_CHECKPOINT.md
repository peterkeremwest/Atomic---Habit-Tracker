## 2. Code changes (by build)
- **v0.1.1: first screens.** No-build multi-file PWA in `public/` (ES modules), IndexedDB storage + sync outbox, service worker (network-first app code), manifest + icons, self-hosted VT323/Courier Prime fonts, terminal theme (green/amber/red, scanlines). Screens: Today, Habits, Categories, Settings. Backup export/import (newest-wins merge).
- **v0.1.2: plain language + structure.** No abbreviations, science names or ASCII bars in the UI. Checked items stay visible. Today sections: Schedule / Daily / Weekly / Monthly / One-time / Lists. Quick-add parser: `#category[/sub]` (auto-creates), full day names, `3x a week`, `monthly 1st`, `x8`, `#timeblock` + time ranges, `#list name: a, b`. Help sheet (`?`). Rename-category sheet.
- **v0.1.3: dates.** Forge-style current date (`S.ui.date`), ◀ ▶, month picker, BACK TO TODAY, Calendar tab with planned/partly/all-done markers. Past days allow backfill, future days are read-only for habits, and the typing bar adds to the viewed day. Typed "ATOMIC" header with a blinking theme-colored cursor that becomes ⚠ offline.
- **v0.1.4: layout.** Typing box moved to the top (persistent `.quick` under `#daybar`). Foldable sections (`//` → `=` animation, remembered). Keyword tags (`#onetime`, `#daily`, `#habit`…) never create categories. Deleting a category keeps its items.
- **v0.1.5: power features.** Undo toast (5 s; records previous versions of every touched record). FOCUS section (pin up to 3 per day, ★). "Move N unfinished to tomorrow". Drag to reorder (⠿ handle, per section, saved as `order`). Task steps (`title: a, b, c`; all steps done → task done). Timer habits (`study 25 min timer`; start/pause, beeps + vibrates at zero, finishes even if the app was closed). Time-block clash warnings (row + toast). Search (⌕ in header). Weekly review (from Calendar, or the Sunday prompt on Today).

## 3. Data / config changes
- IndexedDB `atomic` v1 stores: `elements` (categories), `isotopes` (subcategories), `atoms` (items), `logs` (one per habit per day, id `atomId|date`), `meta` (settings, folded, timers, seeded), `outbox`.
- Item fields: `kind` task|habit|block|list, `repeat` (daily / days / perWeek / perMonth / monthDay), `target` (check / count / timer), `dueDate`, `completedOn`, `date`/`start`/`end` (blocks), `items` (list items or task steps), `focusOn`, `energy`, `order`, plus sync fields `id`, `sourceApp`, `createdAt`, `updatedAt`, `deletedAt`.
- `model.SCHEMA_VERSION = 2`. No migration was needed, because old records stay valid.
- Hosting: `wrangler.jsonc` (Worker `atomic`, assets `./public`, SPA fallback), deployed by Cloudflare Workers Builds on push to `main`.

## 5. Project Progress Summary
*(copied from LINEAGE.md)*

**Historical Milestones**
- v0.1 (2026-09-29): Project initiated. Name, naming system, design direction, feature plan, sync-ready data model and AWS roadmap decided. No code yet.
- v0.1.5 (2026-09-29): First working app, live on Cloudflare (covers builds v0.1.1–v0.1.5). Day screen with Focus/Schedule/Daily/Weekly/Monthly/One-time/Lists sections, typing box with #tags, time blocks with clash warnings, checklists, task steps, counter and timer habits, undo, drag to reorder, date navigation, calendar, weekly review, search, installable and offline.

**Cumulative Capabilities**
Atomic is now a working, installable web app that lives on the phone and works without internet. It is hosted by Cloudflare at atomic.peterkeremwest.workers.dev and rebuilt automatically every time new code reaches GitHub. Everything you enter is kept in a filing drawer on the device itself (IndexedDB). Every change also drops a copy into an outgoing-mail tray, so a future AWS back office can pick them up for cloud sync.

The main screen shows one day at a time. You move between days with arrows or a month calendar, and a BACK TO TODAY button appears whenever you wander off. Past days can be corrected and future days planned. A typing box at the top understands plain sentences. `#fitness workout monday wednesday friday` makes a weekly habit in the Fitness category, `#timeblock work 5pm - 11pm` blocks out time, `#list groceries: eggs, soap` makes a checklist, `move out: pack, clean` makes a task with steps, and `study 25 min timer` makes a habit with a countdown. Unknown tags create new categories, while words like #onetime or #daily only describe the item.

The day is grouped into foldable sections: FOCUS (up to three pinned items), SCHEDULE, DAILY, WEEKLY, MONTHLY, ONE-TIME and LISTS. The `//` in each heading tips over to `=` when a section is folded. Checked items stay visible and crossed out. Lists and step-by-step tasks cross themselves out when every step is done. Time blocks light up while they're running and warn when they overlap. Items can be dragged into your own order, unfinished tasks can be pushed to tomorrow in one tap, and almost every action can be undone for five seconds. The Habits screen shows streaks, this week and the last 12 weeks, the Calendar marks planned, partly done and fully done days, the weekly review sums up each Monday–Sunday, and search finds anything on any day. The look is an old terminal: a typed-out ATOMIC title with a blinking cursor that turns into a warning sign offline, green, amber or red text, and scanlines.

What it can't do yet: nothing leaves the device. There is no account, no backup except a manual export file, no reminders or notifications, and no connection to Forge. Those arrive with the AWS back office in the next phase.

## 6. Next: AWS back office (recommended order)
1. **Foundations:** an AWS Budget alarm, an IAM user/role for deploys, and AWS CLI + SAM CLI on the owner's machine (Forge's setup can be reused).
2. **Amazon Cognito:** add an *Atomic* app client to Forge's existing user pool (`us-east-1_xmt1rEukj`), plus a login screen in Atomic. One account for both apps.
3. **SAM stack `atomic-backend`:** DynamoDB `AtomicTable` (single table, `pk USER#sub`), HTTP API Gateway with the Cognito JWT authorizer, and a Lambda data function (`nodejs24.x`, arm64). The outbox pushes changes, the app pulls on open, and `model.mergeRecords` (newest wins) reconciles. CORS origin: `https://atomic.peterkeremwest.workers.dev` + `http://localhost:3000`.
4. **CloudWatch:** Lambda logs, an error alarm, and a DLQ for failed writes.
5. **Later phases:** an EventBridge bus for Forge ↔ Atomic sync, EventBridge Scheduler + Web Push for reminders, Step Functions for an automated weekly review email, and Bedrock for plan suggestions.
